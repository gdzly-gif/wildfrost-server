WILDFROST CUSTOM TEAM LOBBIES — DEPLOY NOTES

Included files:
- index.html: static game client with peer-to-peer UI removed and invite-code lobby UI.
- server.js: Socket.IO server with server-generated invite codes and 1v1 through 5v5 room capacity/team balancing.

IMPORTANT: Update BOTH the static game client and the existing Render Socket.IO server.

1) Static site
- Replace your static site's index.html with this index.html in the connected GitHub repository.
- Commit and push the change; wait for Render Static Site to redeploy.
- The client connects to https://wildfrost-server.onrender.com.

2) Socket.IO server
- Replace server.js in the existing server repository with this server.js.
- Keep your existing package.json dependencies: express, socket.io, cors.
- Commit and push; wait for the existing Render Web Service to redeploy.
- Check https://wildfrost-server.onrender.com/health returns {"ok":true}.

3) Test
- Open the game in browser A and create a lobby (choose 1v1, 2v2, 3v3, 4v4 or 5v5).
- Copy the generated invite code.
- Open the game in browser B or another device, select the same format, enter the code, and tap JOIN WITH CODE.
- Confirm the roster updates and the player count does not exceed the selected capacity.

Notes
- Lobby codes are generated by the server and lobby formats are fixed at creation.
- The server currently stores lobby state in memory; restarting/redeploying the server clears lobbies.
- This is a prototype multiplayer server, not a production anti-cheat implementation.
